# Nexus-Cli

Nexus-Cli is a TypeScript monorepo for an AI coding CLI/TUI with repo context, provider adapters, sandboxed tool execution, MCP governance, release verification, and local learning artifacts.

## Quick Start

```powershell
pnpm install
pnpm build
node apps/cli/dist/main.js --help
```

For detailed local usage, provider setup, sandbox checks, artifacts, and release verification, see [usage.md](./usage.md).
